### 3. Virtualized List Rendering Bypass
- **[bridge.js](../../bridge.js)**:
  - Implemented `forceDisplayAllContent(actionCallback)`:
    - Finds the scroll container and backs up its height/overflow properties.
    - Stretches the container to `height: auto` and overrides CSS `content-visibility: visible !important` via a temporary stylesheet to force browser rendering.
    - Waits 150ms to allow React virtualizers to mount all off-screen turns in the DOM.
    - Runs the copy action or button scan, then restores original styles and removes the stylesheet.
  - Wrapped `getCopyButtonsList()` and `clickCopyButton()` inside `forceDisplayAllContent()`.
  - Updated `"getCopyButtonsList"` case in `executeCommand` to `await` the asynchronous resolution.
