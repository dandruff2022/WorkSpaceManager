## 2. Persistent Skills Registry (`SkillsRegistry`)
* Implemented the database class in [skills_registry.js](../../utils/skills_registry.js) to manage prompt templates.
* **Separation of Concerns via Prefixing**:
  * User-callable skills starting with `@` (e.g. `@redo`, `@continue`, `@breakdown`, `@shorten`) are exposed to the inline editor autocomplete dropdown menu.
  * System-internal background skills starting with `%` (e.g. `%format`, `%merge`, `%transfer`) are hidden from editor autocomplete and triggered programmatically.
* **Prompt Optimization**: Rewrote all default system/helper skill prompts to be highly detailed and actionable, while keeping description fields short and concise.
* **Seeding & Synchronization**: Seeds all default skills into local storage upon first loading if empty. Includes filtering method `getMatchingSkills(prefix, limit)` returning full template structures.
