# Work Session: Website Profile & Skill Registry Implementation

- Status: completed (Seeded mutable site profiles, created Skills Registry, added autocomplete & action button logic, refactored prompt templates)
- Date: 2026-07-01 11:55:00 -05:00

---

## 1. Summary of Changes

### 1.1 Web Profile Registry (`SiteProfilesRegistry`)
* Created [site_profiles_registry.js](../../utils/site_profiles_registry.js) to manage configuration elements (e.g. selectors for inputs, send buttons, new chat buttons, and message copies) dynamically via `chrome.storage.local`.
* Removed the read-only `isSystem` restriction on default profiles (ChatGPT, Claude, Gemini, Copilot), allowing the user to modify or delete them arbitrarily.
* Integrated the registry with the extension popup ([manager.html](../../ui/manager.html)), background service worker ([background.js](../../background.js)), and manifest ([manifest.json](../../manifest.json)).

### 1.2 Persistent Skills Registry (`SkillsRegistry`)
* Created [skills_registry.js](../../utils/skills_registry.js) to store all system-default prompts and custom user-defined macro templates.
* **Unified Database**: Designed a unified `skills` object inside extension local storage. If storage is empty, it automatically seeds all default templates.
* **General vs. Orchestration Prefix Split**:
  * User-callable skills (like `@redo`, `@continue`, `@breakdown`, `@shorten`) start with `@` and are matched by the inline editor autocomplete dropdown.
  * Internal systemic skills (like `%format`, `%merge`, `%transfer`) start with `%` and are excluded from the autocomplete list, reserved for action buttons or background runs.
* **Expanded Prompt Templates**: Rewrote all default skills with longer, clearer, and more actionable prompts to make the task straightforward for the AI. Shortened description properties to serve as clean titles.

### 1.3 Autocomplete and Button Interactions
* Updated the blueprint plan in [phase_2.1_plan.md](../../doc/plan/phase_2.1_plan.md) and specification in [specification.md](../../doc/specification.md):
  * **Caret Positioning**: VS Code-style autocomplete dropdown absolute-positioned below the text caret in active editors.
  * **Keyboard Selection**: Intercepts `ArrowUp`/`ArrowDown` for focus, `Enter`/`Tab` for committing, and `Escape` for closing.
  * **Visual Spacing**: Auto-wraps injected prompts with empty lines before and after to create a clean paragraph.
  * **Orchestrator Buttons**: Maps clicking Dispatch to `%format` injection, Merge to `%merge` prepending, and Breakdown to `@breakdown` injection.

### 1.4 Integration Refactoring
* Connected [context_transfer.js](../../ui/modules/context_transfer.js) directly to the `SkillsRegistry`. It now reads and writes its prefix prompt using the `%transfer` skill entry rather than a standalone `transferPromptText` storage key, maintaining bi-directional consistency across the extension.
