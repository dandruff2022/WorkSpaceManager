# 2026-10-26 — Demo release v0.6.0, first build

- **Goal:** First working build of the Phase 2.5 plan, ready for the user to try on ChatGPT and Gemini in Chrome.
- **Timing:** 2026-10-26 ~16:45–17:30 CDT.
- **Status:** completed (needs the user's hands-on test).
- **What changed:**
  - `ui/manager.html`: three screens (Send, Prompts, Settings) + Debug (only with `?debug`); no web fonts; Context
    Transfer, Broadcast and Orchestrator views removed from the page (their JS files are kept, not loaded).
  - `ui/modules/send.js` (new): tab list with checkbox, site name, live status chip, click-to-jump, per-tab
    "Quick prompt" menu; composer with `@` autocomplete and Cmd/Ctrl+Enter; one-line result message.
  - `background.js`: "Answer ready" notification when a watched tab goes working → complete while not in front;
    click focuses the tab; can be turned off (`notifyWhenDone`).
  - `ui/manager.css`: rewritten — flat, system font, one accent color, follows OS light/dark.
  - `ui/manager.js`: new module map, notification setting, debug view hidden unless `?debug`.
  - `ui/modules/skills.js`, `utils/skills_registry.js`: plain wording; default prompts are @redo, @continue,
    @shorten, @check; old workflow prompts (@breakdown, %transfer, %format, %merge) removed on load.
  - `content.js`: the in-page `@` pop-up is now on by default (was off until enabled in the UI).
  - `manifest.json`: v0.6.0, `notifications` permission, PNG icons 16/32/48/128; `icons/icon.svg` redrawn.
- **What was found:** the in-page `@` pop-up was off by default, so a new user would never see the headline
  feature. Status updates only flow while the manager is open (observers are registered from the Send view).
- **Validation:** `node --check` on all changed JS; headless-Chrome screenshots of Send / Prompts / Settings in light
  and dark. Not yet run as a loaded extension.
- **Conclusion:** First build is ready to try.
- **Next steps — Codex can proceed:** fix whatever the trial finds; README with GIFs; tick roadmap; tag and release.
- **Next steps — Human reflection:** after trying it, which of Send / quick prompt / notifications feels useful.
- **Human action:** reload the extension in Chrome and try it on ChatGPT and Gemini.
