## 1. The Diagnosed Root Cause

When the Orchestrator panel loaded, it queried open AI tabs, dynamically generated visual status pills, and sent `observeGenerationState` initialization messages to each tab. 

However, we encountered a bug where all tabs displayed as `"Initializing"` permanently.

### **The Lifecycle Reset Cycle**
1. On startup, `initializeTabObservers()` clears the container (`observersContainer.innerHTML = ''`) and creates a new pill for each tab, defaulting its label to `"Initializing"`.
2. It sends the `observeGenerationState` message to the tab to attach the MutationObserver.
3. The content script immediately responds with an initial state check message (`bridge_state_change`), which updates the status badge to `"complete"` or `"newchat"`.
4. **The Trigger**: The user switches tabs or a tab reloads. This triggers `onActivated` or `onUpdated` listeners, causing `initializeTabObservers()` to run again.
5. **The Desync**: The function clears the container and rebuilds all pills, resetting them to the default `"Initializing"` state. Since the tab was already registered in the `observedTabs` set, the script skips re-sending `observeGenerationState`.
6. **The Result**: No new status messages are sent, and the pills remain stuck showing `"Initializing"` forever.

---

## 2. Applied Fix & Instrumentation

### **A. Popup State Cache (`ui/modules/orchestrator.js`)**
We introduced a persistent state cache (`tabStatesCache = {}`) in the Orchestrator scope:
* **Storage**: When a `bridge_state_change` message is received, we store the state in `tabStatesCache[tabId] = state`.
* **Restoration**: During tab scanning/recreation inside `initializeTabObservers()`, the dot class and text label are populated from the cached state:
  * If cached state exists (e.g. `complete` or `newchat`), it renders immediately with the correct color/label (e.g. Green dot - `"Observing (Idle)"`).
  * If no state is cached yet, it falls back to `"Initializing"` (Grey dot).

### **B. Diagnostic Console Logs**
Added severity-tagged logs to trace the lifecycle:
* `[OrchestratorModule] Rendering Tab ${tab.id} pill. Cached state: ${cachedState || 'none'}`
* `[OrchestratorModule] MutationObserver registration success for Tab ${tab.id}`
* `[OrchestratorModule] Received state broadcast for Tab ${tabId}: ${state}`
