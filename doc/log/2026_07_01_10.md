# Work Session: Storage Capacity & Plan Solidification

- Status: completed (Added unlimitedStorage permission, finalized Phase 2.1 plan structure, refactored roadmap drafts)

---

## 1. Unlimited Storage Permission
* Added `"unlimitedStorage"` to the permissions list in [manifest.json](../../manifest.json#L10) to completely bypass the default 5MB storage limit of `chrome.storage.local`.
* This ensures that user-defined site profiles and large macro templates will not fail due to disk quota limitations.

---

## 2. Roadmap Refactoring
Updated [roadmap.md](../../doc/roadmap.md) to reflect new storage and skill models:
* **Removed Draft Persistence**: Removed the "Module-Specific Drafts & Configurations" section in Phase 2.
* **Skill Redirection**: Re-allocated the Context Transfer prompt template to be saved under the new system skill `@transfer` inside the Persistent Skills Registry.
* **Ephemeral Broadcasts**: Set the Broadcast prompt input to be fully ephemeral (in-memory only), as users draft unique contents per run.
