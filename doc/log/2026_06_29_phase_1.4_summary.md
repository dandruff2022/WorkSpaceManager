## 2. Detailed Breakdown of Module Implementations

### **A. Broadcast Module (`ui/modules/broadcast.js`)**
* Implemented strict domain filtering for target tabs (ChatGPT, Claude, Gemini, Copilot).
* Created a dynamic checkable active tab list.
* Built a **Focus-Switch & Restore loop** that sequentially focuses target background tabs for 80ms to bypass browser constraints on background `execCommand` injections, pasting prompt strings, triggering send, and returning focus to the original active tab.
* Embedded JIT script injection through message routing redirection.

### **B. Context Transfer Module (`ui/modules/context_transfer.js`)**
* Designed a horizontal, side-by-side selection layout with Outfit semi-bold labels and an active center paper-plane action button.
* Enforced **Strict Tab State Rules**:
  * **FROM (Source)**: Only displays tabs in the `"complete"` (loaded response) state.
  * **TO (Target)**: Only displays tabs in the `"empty"` or `"newchat"` state.
* Built a **Multi-Turn Extraction & Insertion Loop**:
  * Traverses all sequential turns in the source tab (both user prompts and AI responses).
  * Prefixes turns with `"user said:\n"` and `"ai responsed:\n"`.
  * Joins turn text blocks with newline (`\n`) characters.
  * Pastes consolidated context into the target input box and automatically clicks the send button to submit the migrated history.

### **C. Orchestrator Module & Global State Cache (`ui/modules/orchestrator.js`)**
* Patched `background.js` to append `sender.tab.id` to state broadcasts.
* Created a centralized `window.__agy_tab_states` registry in `ui/manager.js` to track states.
* Queries initial state values via `"scanInitialState"` on startup and listens for runtime broadcasts to keep states in sync.
* Mounts MutationObservers concurrently in all open AI tabs, displaying a dashboard with glowing traffic light state dots (Green = Idle, Blinking Yellow = Generating, Purple = Empty).
* Rendered static canvas representations of ChatGPT and Claude node boxes prepared with drag-handles and anchors.

### **D. Connection & Schema Validation (`ui/modules/connection.js`)**
* Created a profile layout JSON validator verifying required schema tags (`siteName`, `selectors`, `inputSelector`, `sendButtonSelector`, `messageTurnSelector`).

### **E. Visual Polish (`ui/manager.css`)**
* Added global dark-mode checkbox styling overrides using custom appearance properties and inline SVG checkmarks to blend seamlessly with the extension's premium layout.
