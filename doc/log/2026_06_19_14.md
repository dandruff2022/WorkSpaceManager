### What was found

- SVG icons are supported for actions/sidebar actions in MV3 across modern versions of Firefox and Chrome, avoiding multi-size PNG generation.
- Dynamic side panels can be managed from background scripts by calling `chrome.sidePanel.open` inside action triggers.
- Firefox MV3 throws an installation error if only `background.service_worker` is specified when service workers are disabled in the browser profile. Providing both `service_worker` (for Chrome) and `scripts` (for Firefox) inside the `background` block resolves the error, allowing both browsers to load the same manifest.
- In side panel mode (or on narrow screens), the vertical sidebar switches to a horizontal scrollable menu at the top. The sidebar footer is hidden to preserve vertical space, making it impossible to switch back to Window mode if the control is placed there. Transitioning the View Mode Selector to a global header toolbar on the right content area ensures it remains visible and interactive in all states.
- Chrome-only keys like `"sidePanel"` in permissions and `"side_panel"` in the manifest root will cause Firefox to emit warnings on installation (e.g. `"Warning processing side_panel: An unexpected property was found"`). These warnings are fully non-blocking and can be safely ignored; they are required to support Chrome side panels out of the box using a single unified `manifest.json`.
