### What was found

- **Main World Security Boundaries**: Content scripts are isolated and cannot access or override properties on the page's global `window.navigator` directly. Overriding browser APIs requires appending `<script>` tags to the DOM to execute in the page's Main World context.
- **Background Tab Throttling**: Browsers restrict timer resolution (`setTimeout`, `setInterval`) on background tabs to save battery and memory. However, DOM mutations and CustomEvent listeners run dynamically inside the main thread's event loop, validating event-driven tracking as highly robust for background status fetching.
- **Context Console Relay**: Ordinary webpage scripts lack access to `chrome.runtime`. To run our test runner directly in the page console without switching execution environments, we created a CustomEvent request-response relay in the content script to proxy commands to and from `background.js`.
