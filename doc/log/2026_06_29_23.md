## 2. Multi-Turn State & Formatting Rules

We enforced target filtering and sequential formatting:
* **FROM Selector**: Only lists tabs whose state matches `"complete"`.
* **TO Selector**: Only lists tabs whose state matches `"empty"` or `"newchat"`.
* **Centralized Tab State Cache**: Declared `window.__agy_tab_states = {}` inside the global [ui/manager.js](../../ui/manager.js#L207). It queries initial states via `scanInitialState` and updates reactively on `bridge_state_change` broadcasts.

### **The Multi-Turn Automation Flow**
1. Switched active tab focus to the source tab.
2. Queried the sequential copy buttons list (`getCopyButtonsList`).
3. Iterated through **all** turns (both User prompts and AI responses) sequentially:
   - Programmatically click each copy button (`clickCopyButton`).
   - Prefix user prompts with `"user said:\n"`.
   - Prefix AI responses with `"ai responsed:\n"`.
   - Append a newline character `\n` after each turn.
4. Switched active tab focus to the target tab.
5. Hydrated the target input box (`writeToInput`) with the consolidated multi-turn text block.
6. Triggered the send action (`clickSend`) on the target tab to automatically submit the context.
7. Returned focus to the user's starting tab.
