# Workspace Manager v0.7.0 — demo

A goal, a few AI chats and one final answer. No API keys or new account needed.

## New since v0.6.0

- **Projects:** Describe → Plan → Run tasks → Combine → Continue. Run parts in separate ChatGPT/Gemini chats, save answers and carry a short, versioned project memory into a new chat.
- **Notes:** write your own notes or right-click **Save to Notes** on a page. Ask AI to edit with **Tweak**, review the change and apply only what you want.
- **Answer styles:** choose how AI should answer. One `;;` picker has Prompts, Styles, Notes and Memory tabs; **≡ Answer** opens styles in the manager.
- **Side panel:** the manager opens beside your chat by default. A separate window is still available in Settings.
- **Send** still sends one prompt to several selected chat tabs.

## Install

1. Download `workspace-manager-v0.7.0.zip` and unzip it.
2. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and select the folder containing `manifest.json`.
3. Pin Workspace Manager and click its toolbar icon to open the side panel.
4. Reload already-open chat tabs. Sign in to ChatGPT or Gemini as usual.

## Known limits

- This is a demo. Check important AI answers yourself.
- ChatGPT and Gemini are tested; Claude and Copilot profiles are untested.
- Chat tabs briefly come forward while typing or reading. Projects open several chats; planning, tasks and memory updates are temporary by default, while Combine and Continue are normal chats.
- Website changes can break the site's selectors in `presets/`.

Data stays in local browser storage except messages sent to chat sites through the extension. No separate server or analytics.
